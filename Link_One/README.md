# Link-One

- 담당: **신진섭**
- 역할: 현장 구조 정보와 구조 대상자의 위치·상태를 다루는 프로젝트.
- 현재 상태: 협업용 폴더와 안내 문서만 준비했습니다. 실제 코드와 자료는 담당자가 추가합니다.

## 자료 추가

프로젝트 소스·설정 예제·관련 문서를 이 폴더 안에 넣어 주세요. 기존 프로젝트 구조와 개발 방식을 유지해도 됩니다. 업로드 후 필요한 설치·실행 명령과 환경변수 이름을 이 README에 기록합니다. 비밀키 값·실제 개인정보·실행 DB는 올리지 않습니다.

## 협업 방향

AI 상황실 및 RESAID AI와 같은 사건의 구조 현황·대상자 상태·확인 요청을 주고받는 방향을 검토합니다. API 주소·인증·데이터 형식은 팀 협의 후 확정하며 현재 연동은 구현되지 않았습니다.
