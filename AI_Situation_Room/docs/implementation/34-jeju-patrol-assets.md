# 34. 제주청 경비함정 후보 목록

2026-09-30. 사용자가 Link-One에 등록된 제주 지역 경비함정을 해온 가용세력에 추가하도록 요청했다.

## 추가 자료와 출처

기존 읽기 전용 연결로 Link-One의 제주지방해양경찰청(REGIONAL)→제주/서귀포해양경찰서(DISTRICT)→현장 세력(FIELD) 등록 관계를 확인했다. 이번 조회에서 경비함정으로 확인한 아래3척을 `prototype/manuals/jeju_assets.json`에 등록했다. 서귀포 관서 아래에는 이번 조회 시 FIELD 등록 행이 없었다. 이는 실제 서귀포 보유 함정이 없다는 뜻이 아니다.

| 해온 asset_id | 등록 명칭 | 등록 소속 |
|---|---|---|
| jeju_1505 | 1505함 | 제주해양경찰서 |
| jeju_3012 | 3012함 | 제주해양경찰서 |
| jeju_p36 | P-36 | 제주해양경찰서 |

제주청 전체 실제 편제를 수집했다고 주장하지 않는다. 함번호만으로 톤수·속력·장비·승조원·좌표를 추정하지 않았다. Link-One 계정 ACTIVE는 계정 활성 상태여서 실제 가용성으로 복사하지 않는다. 각 함정의 availability는 미확인이며 출동 가능 여부와 도착시간은 추가 확인한다. 명칭·소속의 조회일과 원천을 카탈로그에 기록한다. 인증 정보·원본 계정 UUID는 넣지 않는다.

이는 확인 시점의 정적 후보 목록 추가다. 알림3초 수신이나 환자/세력 위치의 실시간 동기화를 확장한 변경은 아니다. Link-One 원격 DB는 수정하지 않았다.

## 사건별 선택과 모델 연결

- `manuals.catalog_ids(session)`는 facts.location의 제주/서귀포 표시를 제주 카탈로그로, 기존 묵호/동해시/동해항/울릉/독도 표시를 동해 카탈로그로 선택한다. 두 지역이 같이 나오거나 다른 지역 표지가 섞이면 목록을 선택하지 않는다. 좌표 기반 관할 추정은 구현하지 않았다.
- 위치가 미확인인 Link-One 세션에는 명명된 후보를 보내지 않는다. 일반 훈련 세션의 위치 미지정 동해 기본값은 기존 동작을 유지한다.
- `manual_evidence(session)`는 해당 사건의 후보만 전달한다. 인자 없는 `/api/manuals`는 자료 열람용 전체 목록을 반환한다.
- `tools.evidence_for`는 모든 세션에 `resource_scope`의 catalog_ids/named_dispatch_allowed를 전달한다. 계정 소속이나 location_force를 실제 출동 가능한 세력으로 오인하지 않도록 한다.
- 공통 모델 지침은 실제 제공된 donghae_assets/jeju_assets만 참조하도록 한다. 제주 사건에 동해 예인3호정/방제3호정을 지시하던 고정 표현은 해당 지역의 예인/방제 필요 검토로 바꿨다.
- `normalize_orders(items, session)`는 지역 밖의 함정 ID를 제거하고 해당 후보의 이름·근거를 보충한다. Engine은 배정·모든 요원 보고·최종 종합에서 적용한다. 잘못된 후보를 화면에서만 숨기는 처리가 아니다.
- 기존 키워드로 동해 출동안을 자동 보충하는 로직은 동해 사건에만 적용한다. 제주 목록만으로 함정 우선순위·거리·장비를 확정하지 않으며 제주 후보 선택은 제공된 근거를 읽는 모델이 수행한다.

## 화면·저장 계약

`Store.snapshot`의 resource_scope는 모든 세션에 `{named_dispatch_allowed, catalog_ids}`로 포함된다. `app.js`는 사건의 catalog_ids에 맞는 자료 버튼을 보여준다. 제주 사건 우측 세션 자료에 **제주청 경비함정 후보 목록**이 나타나며 클릭하면3척의 명칭·소속·제약을 볼 수 있다. 보고 근거의 jeju_assets도 사람이 읽는 제목으로 표시한다.

기존 보고·요원 지시·원문은 보존하며 목록 추가만으로 AI를 실행하지 않는다. 이미 생성된 보고의 ‘특정 세력 제안 불가’ 문구를 소급 변경하지 않는다. 다음 사용자 분석 요청부터 새 근거가 적용된다. 이미 열린 페이지는 새로고침해야 최초 로드한 자료 목록도 갱신된다.
