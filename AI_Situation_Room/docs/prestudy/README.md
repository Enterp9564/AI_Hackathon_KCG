## 프로젝트에 연결할 때

우리 HAEON(해온)은 기존 언어모델 API를 사용하는 앱이다. 역할을 나누거나 프롬프트에 전문 지침을 넣었다고 별도의 전문가 모델을 학습한 것은 아니다. 현재 상태는 [프로젝트 인수인계](../../13_현재상태_요구사항_인수인계.md)를 따른다.

이번 학습자료는 앱 동작을 변경하지 않는다. 자료 안의 ‘CNN 신고 분류기’, ‘평가 점수’, ‘학습 데이터’는 교육용 설계·예시다.

## 참고자료 사용 방식

교육 범위는 첨부 이미지에서 읽었다. 개념 확인에는 원 논문과 공식 개발 문서를 사용했고, 설명·사고 예시·문제·숫자는 예습용으로 직접 구성했다. 각 본문의 링크는 더 공부할 때 참고하며 논문 전체를 읽는 것은 예습 필수 과제가 아니다.
