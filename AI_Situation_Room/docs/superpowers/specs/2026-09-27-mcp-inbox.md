# MCP 외부 보고 수신함 설계

사용자가 제공한 2026-09-27 화면 흐름을 구현 기준으로 삼는다.

- 기존 로컬 UI/API와 별도 MCP 수신 포트. stdlib HTTP, SQLite, 기존 JS 유지.
- Link-One / RESAID AI별 토큰으로 송신자를 식별. 상황실에서 외부 사건 ID를 세션에 먼저 연결.
- 수신 원문, 수신 시각, 상태, 승인 지시/run 연결, 처리 이력을 영속 저장.
- (프로젝트, report_id)로 멱등 처리. 같은 ID의 다른 본문은 충돌. 기존 원문 보존.
- 인용 승인과 기존 지시 enqueue를 같은 SQLite 트랜잭션에서 처리. 기존 Engine 큐 사용.
- 인용은 확인되지 않은 외부 주장. 인용 실행에서 자동 facts 갱신 금지. 이후 실행에서도 외부 주장과 사용자 신고를 구분.
- 알림 버튼 → dialog 패널 → 인용하여 전송/나중에/반영 안 함. 기존 초안은 유지.
- MCP 2025-11-25 Streamable HTTP JSON 응답 부분집합. 초기화, ping, tools/list, tools/call. SSE/리소스/프롬프트/OAuth 미구현.
- 기본 MCP 비활성·loopback. 핫스팟 IP 명시 시 LAN 수신. 테스트 토큰 사전 공유, 실제 운영에는 TLS·인증 확장 필요.
- 실제 타 프로젝트·핫스팟 장비 연동은 준비 이후 별도 검증. 데모 송신 CLI 제공.
