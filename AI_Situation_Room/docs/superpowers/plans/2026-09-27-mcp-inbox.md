# MCP 수신함 구현 계획

Goal: 외부 보고를 수신함에 보관하고 담당자 승인으로만 기존 지시 실행에 연결한다.
Architecture: SQLite 원자적 승인 + 기존 Engine + 별도 인증 HTTP MCP listener + 로컬 승인 UI.
Stack: Python stdlib, SQLite, HTML/CSS/JavaScript.
Spec: ../specs/2026-09-27-mcp-inbox.md

1. 수신 격리·중복·사건 검증·처리 이력·원자적 승인 테스트 작성 후 실패 확인.
2. Inbox 저장소와 기존 enqueue 연결, 외부 주장 facts 반영 차단 구현.
3. MCP JSON-RPC/인증/입력 검증 테스트 후 수신 서버·토큰 준비·데모 송신 구현.
4. 기존 send 재사용, 초안 보존, 프로젝트 알림·플로팅 패널·사건 연결 UI 구현.
5. 단위/HTTP 회귀, JS 검사, 격리 DEMO 브라우저 검증. 결과와 미실행 검증 구분.
6. 피처별 상세 구현 문서, 핫스팟 안내, 인수인계/PROGRESS 현행화.
