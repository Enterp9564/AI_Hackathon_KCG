- Ruling: 원본 폴더의 Git 기준점은 오래되고 코드 대부분이 미추적이다. 관리형 worktree에 현재 공개 소스·문서를 복사하고 9798cb9 기준 커밋을 만들었다. 기존 runtime·키를 복사하지 않았다. 완료 후 충돌 검사를 거쳐 이번 변경만 원본에 반영한다.
- Ruling: M1은 기존 14개 authored summary의 검증·스냅샷을 사용한다. 원문 전체 파싱이나 구조/전문 검토 완료로 표시하지 않는다.
- Pre-flight: corpus → retrieval은 ID/본문/출처/제한 필드를 보존한다. retrieval → engine → store/UI는 동일 evidence ID와 본문 스냅샷으로 연결한다. 기능 off와 기존 호출 서명은 호환을 유지한다.

- Final: Ruling: 기존 워크스페이스에 사용자가 진행한 변경이 많아 Git merge 대신 기준 커밋과 파일 단위 충돌 검사를 거쳐 이번 변경만 복사한다. 원본 키·기존 runtime은 보존하고 새 검색 전용 runtime만 준비한다. 기준점 이후 충돌이 있으면 해당 파일을 덮어쓰지 않는다.
