# 01 · 주요 알림 화면과 사용자 흐름

2026-09-29 · **제안 / 미구현** · [개선안 전체](../04-main-alerts.md)

## 1. 고정 요약 영역

헤더 아래 공통 영역에 `주요 알림`을 둔다. 해온/링크온 원본 화면보다 바깥에 배치하며 스크롤 시 상단에 붙인다. 환자 알림은 현재 선택된 **해온 세션** 기준이다. 원본 링크온에서 다른 사건을 선택해도 해온 사건이 자동으로 바뀌지 않음을 표시한다.

구성 예시의 숫자는 직전 관측을 사용한 설명용이다.

```text
주요 알림 · 현재 해온 사건
최신 판정 8명 | 즉시 확인 5 | 30분 분류 2 | 기타 출처 분류 1 | 미열람 8
마지막 수신 성공 HH:MM:SS                    [전체 점검 열기]
```

‘미열람’은 다른 분류와 중복되는 별도 지표다. 모든 숫자를 더해 총원으로 해석하지 않도록 구분한다. `즉시 확인` 등은 링크온 AI의 요청 긴급도이며 원본 명부의 의료 중증도와 별개다. 실패/미연결/첫 수신 대기를 0명으로 표시하지 않는다.

읽음 여부와 무관하게 현재 중요 판정의 요약은 남긴다. 색과 함께 문구·아이콘을 사용한다. 자동 경고음은 첫 범위에 넣지 않는다.

### 버튼 강조: 수신부터 클릭까지

- 새 판본 수신 시 환자 알림 버튼에 붉은 테두리·은은한 빛의 반복 효과와 `새 알림` 표시를 켠다. 상황실장 처리 중 초록 강조와 같은 시각적 방식이며 빠르게 깜박이지 않는다. 시간이 지나도 자동으로 끄지 않는다.
- 사용자가 알림 버튼을 눌러 패널이 정상적으로 열리면 그 시점까지 수신한 판본의 강조만 멈춘다. 버튼의 기본 빨간색과 건수는 유지한다. 목록 진입만으로 8건을 모두 읽음/처리 완료로 바꾸거나 AI를 실행하지 않는다.
- 패널을 여는 데 실패하면 강조를 유지한다. 클릭 직후 도착한 판본은 클릭으로 확인한 집합에 넣지 않는다.
- 이후 새 판본이 오면 패널이 열려 있어도 다시 강조한다. 알림 버튼을 다시 누르면 현재 패널로 포커스를 옮기고 현재 수신분의 강조를 멈춘다. 패널을 닫거나 화면을 전환하는 동작은 강조 해제로 취급하지 않는다.
- 같은 자료의 반복 조회·재수신만으로 다시 강조하지 않는다. 사건별로 강조 상태를 분리한다.
- 움직임 줄이기 설정에서는 반복 효과 대신 고정 테두리와 `새 알림` 표시를 유지한다. 키보드 Enter/Space로 버튼을 눌러도 같은 동작을 한다.

## 2. 주요 알림 패널

현재 빨간 버튼과 새 요약 영역 모두 같은 패널을 연다. 데스크톱에서는 옆에 고정할 수 있는 비모달 패널이며, `넓게 보기`로 전체 비교 영역을 확보한다. 채팅·상황판을 조작할 수 있고 페이지 전체를 어둡게 막지 않는다.

```text
주요 알림 · 현재 사건                         [넓게 보기] [닫기]
환자 | 선박·현장 | 통신·자료
전체 / 미열람 / 즉시 확인 / 판정 후 기록 변경    검색

선택  이름/식별  출처 긴급도  핵심 사유  관리 상태  기록/분석 경과
□     환자 A    즉시 확인    한 줄 요약  수신본 기준 …
□     환자 B    30분 분류    한 줄 요약  확인 불가   …
…

[선택 판본 읽음 처리] [선택 판정 함께 검토]
                         오른쪽: 선택 환자의 원문·시점·근거
```

미연결 분류는 건수 0으로 오인시키지 않는다. 선박·현장 탭은 해당 연동 단계부터 활성화한다. `함께 검토` 버튼도 실제 API가 제공되는 단계에서만 활성화한다. MCP 보고 메뉴는 환자 긴급도와 섞지 않고 기존 수신함으로 연결한다.

## 3. 8명을 비교하는 목록

- 기본은 환자당 한 행이다. 요약 두 줄 이내, 긴 내용은 상세에서 읽는다.
- 넓게 보기의 1920×1080 기준에서 제목·필터·8행을 함께 볼 수 있도록 검증한다. 8개 큰 카드를 세로로 쌓지 않는다.
- 열: 선택, 이름/식별, 출처 긴급도, 핵심 사유, 관리 상태/위치, 기준 기록 및 분석 경과. 관리 상태가 없으면 `확인 불가`다.
- 출처 긴급도 우선으로 정렬하되 분석 실패·코드 미확정·판정/현장 기록 불일치를 별도로 눈에 띄게 표시한다. 이것은 의학적 우선순위를 새로 계산하는 기능이 아니다.
- 행을 선택하면 목록은 유지한 채 옆 상세가 바뀐다. 선택 체크박스와 상세 열기는 별도 동작이다.
- 목록 표시, 필터, 체크박스 선택은 읽음 처리하지 않는다. 상세 열람은 기존처럼 해당 판본의 열람 이력을 남긴다.

이름은 기존 명부 수신본에서 가져오며 동명이인은 식별자를 함께 표시한다. 명부 수신 시각을 볼 수 있어야 한다. 최신 위치로 확인되지 않은 과거 위치를 현재 위치처럼 강조하지 않는다.

## 4. 상세와 시점

상세는 요약 → 원본 긴급도/관리 상태 → 시점 → 근거/부족 정보 → 검토 이력 순서다. 원본 코드와 긴 원문은 접을 수 있다. 현재 읽는 판본을 고정하고 새 판본이 오면 `새 판정 도착 · 최신 보기`를 표시한다. 자동으로 본문을 바꾸거나 읽음으로 만들지 않는다.

시간은 다음을 구분한다.

- **판정 기준 기록:** 분석이 참고한 자료 시각. 환자의 실제 관측 시각과 같다는 보장이 없으면 그렇게 쓰지 않는다.
- **분석 완료:** 링크온이 판정을 만든 시각.
- **해온 수신/확인:** 해온이 자료를 받거나 변경 유무를 확인한 시각.
- **명부 수신:** 위치·이송·종결 설명이 어떤 수신본 기준인지 나타내는 시각.

숫자 코드 WITHIN_30으로 수신 시점부터 30분 타이머를 만들지 않는다. 오래됐다는 위험 기준이 합의되기 전에는 경과 시간과 기록 불일치를 표시한다.

## 5. 읽는 동안 갱신과 사건 전환

배경 수신·상단 집계는 계속 갱신한다. 패널을 읽는 동안 행 순서는 유지하고 신규/변경 배지를 붙인다. 담당자가 `목록 갱신`을 누르거나 다시 열 때 정렬한다. 키보드 포커스·스크롤·선택을 보존한다.

선택한 판본에 변경이 생기면 그 행을 `선택 후 변경`으로 표시하고 전송을 막는다. 사용자가 최신 내용을 확인해 다시 선택한다. 새 환자를 자동으로 선택 목록에 넣지 않는다.

해온 사건 변경 시 패널의 선택/상세/전송 미리보기는 초기화한다. 돌아올 때 과거 사건 선택을 자동 복원하지 않는다. 링크온 iframe의 로그인·화면 유지 정책과 해온 알림의 사건 격리는 별도다.

## 6. 모바일·대형 화면

모바일은 핵심 열만 담은 한 줄 요약과 펼침 상세를 사용한다. 가로로 긴 표를 강제하지 않는다. 전체 화면 패널에서 뒤로가기를 제공하고 채팅 초안은 유지한다. 390px에서 버튼·텍스트·포커스 가림을 검증한다.

대형 화면은 고정된 사건의 주요 알림 요약을 계속 보여준다. 상세 읽음/일괄 처리/AI 실행 버튼은 두지 않는다. 현재 `monitor`에서 환자 조회를 건너뛰는 코드를 수정할 때 조회만 허용하고 쓰기 동작은 분리한다.
