# 사고해점 기상정보 연동 검토

> 2026-09-28 대화 정리. API 후보와 설계 방향이며 신규 기상 기능 구현 완료 기록이 아니다.

## 사용자 방향

사고해점의 풍향·풍속·파고·시정·날씨를 조회하되 현지에서 보내는 기상 보고를 주된 자료로 사용한다. API 자료는 주변 관측과 예보를 보완하는 용도다.

## 확인한 무료 API 후보

- **Open-Meteo Weather + Marine:** 위경도 기준 풍향·풍속·돌풍·시정·날씨와 파고·파향·파주기·너울을 조합할 수 있다. 모델 자료이므로 현장 실측과 구별한다. 비상업용 무료 API는 하루 10,000회 제한과 가용성 보장 없음 조건이며 상업적 이용은 별도 조건을 확인한다. [Weather](https://open-meteo.com/en/docs), [Marine](https://open-meteo.com/en/docs/marine-weather-api), [가격·이용 조건](https://open-meteo.com/en/pricing).
- **기상청 해양기상부이·파고부이:** 풍향·풍속·돌풍·유의파고·수온 등 지점 관측을 보조 자료로 사용한다. 무료, 활용신청·인증키 필요. 각 관측소가 제공하는 항목·관측 시각·결측 여부를 확인한다. [API허브 명세](https://apihub.kma.go.kr/apiList.do?seqApi=3), [공공데이터포털](https://www.data.go.kr/data/15139440/openapi.do).
- **국립해양조사원 해무관측소:** 주요 무역항 인근 10개소의 시정·풍향·풍속·기온·습도 등 관측. 무료, 활용신청·인증키 필요. 모든 사고해점을 포괄하지 않는다. [공공데이터포털](https://www.data.go.kr/data/15142519/openapi.do).

이용 조건과 제공 항목은 2026-09-28 공식 문서 조회 기준이다. 이번에는 실제 좌표 응답이나 인증키 발급·공공기관 API 호출을 시험하지 않았다.

## 권장 표시와 처리

1. 현장 보고는 보고자·관측 시각·위치를 함께 우선 표시한다.
2. 주변 관측은 관측소명·사고해점과의 거리·관측 시각을 표시한다. 주변 값을 사고해점 실측으로 바꾸지 않는다.
3. 모델 예보는 해당 좌표 부근의 예측 격자·유효 시각·조회 시각을 구별한다.
4. 출처 간 값이 다르면 원문을 보존하고 차이를 표시한다. 자동 평균·덮어쓰기로 충돌을 숨기지 않는다.
5. 결측은 미수신으로 표시한다. 시정 결측을 시정 양호로 해석하지 않는다.
6. 단위와 관측 정의를 유지한다. 유의파고와 현장의 추정 파고를 같은 측정값으로 간주하지 않는다.

## 현재 코드와 다음 범위

`prototype/tools.py`의 weather는 Open-Meteo 기온·풍향·풍속을 수동 조회한다. 시정·날씨 코드·Marine 파고와 국내 관측 API는 미연동이다. 우선 기존 조회에 시정·날씨·Marine 자료를 추가하고, 이후 국내 관측을 보완하는 방안을 검토했다. 자동 갱신 주기·신선도 기준·관측소 선정 거리·자료 승인 방식을 확정한 뒤 구현한다.
