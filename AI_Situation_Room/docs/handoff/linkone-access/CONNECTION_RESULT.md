## 확인 결과

- 서버 ED25519 호스트키: 전달받은 지문과 일치하는 키로 검증
- SSH: 114.110.181.118:10022 / linkone-link 공개키 인증 및 포트 포워딩 성공
- DB: 로컬 터널 127.0.0.1:15432 → linkone / linkone_ro 접속 성공
- 읽기 전용 트랜잭션 확인
- public의 일반·파티션 테이블 INSERT/UPDATE/DELETE/TRUNCATE 및 컬럼 INSERT/UPDATE 권한 메타데이터 점검: 쓰기 권한 발견 없음
