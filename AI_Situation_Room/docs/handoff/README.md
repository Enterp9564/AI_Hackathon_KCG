# 다른 AI 플랫폼에 해온 전달하기

> 기준일 2026-09-28. 현재 소스와 기존 명세를 대조한 **문서 기반 재구현 패키지**다. 다른 AI가 실제로 재구현해 통과한 결과물은 아직 아니다.

## 전달할 파일

**한 파일만 올릴 수 있으면 [HAEON_REBUILD_SPEC.md](HAEON_REBUILD_SPEC.md)를 전달한다.** 별도 앱 소스를 읽지 않아도 제품 범위·기능 계약·데이터·API·화면·실행 순서·프롬프트·검증 사례·매뉴얼·세력 목록·청해호 원문을 읽을 수 있도록 합쳤다.

여러 파일/ZIP을 받을 수 있으면 `HAEON_REBUILD_DOCS.zip`을 전달한다. ZIP에는 통합 명세, 이 안내, [manifest.json](manifest.json)만 있다. 앱 소스·키·토큰·runtime·기존 사용자 세션은 없다. manifest는 문서와 대조 코드의 해시를 기록하며 코드 자체를 포함하지 않는다.

## 함께 보낼 요청문

> 첨부된 HAEON_REBUILD_SPEC.md를 읽고 HAEON(해온)을 재구현해 주세요. 첫 번째 목표는 현재 기능과 데이터 경계를 재현하는 것입니다. 최신 요구와 현재 코드 차이는 ‘미구현 개선’ 절로 분리되어 있으므로 이를 이미 구현된 사실로 혼동하지 마세요. Python 3.11+ 표준 HTTP·SQLite·HTML/CSS/JavaScript를 유지하고 작업 1~9를 순서대로 구현·검증하세요. 문서의 모듈 인터페이스와 HTTP/JSON 필드명을 맞추고 세션 격리·원문/정정 보존·멱등성·실패 표시·외부 보고 승인 경계를 지켜 주세요. 초기에는 DEMO와 가상 데이터로 확인하고 실제 API 키는 제가 로컬에 입력할 수 있게 준비하세요. LIVE 접근이 불가능하면 미실시로 보고하고 다른 모델이나 DEMO로 몰래 대체하지 마세요. 각 단계에서 구현 파일·실행법·관측한 시험 결과·미완료를 남겨 주세요. 현재 복원 후에는 경량 배정과 핵심 1~2건 선정의 개선 계획을 별도로 제시해 주세요.

## 내용 구성

- 제품명·범위·현재 상태/미완료 구분, 기능별 명세 01~23.
- 함수 연결·DB·JSON·HTTP·MCP·동시성·프롬프트·화면 배치/치수.
- 계약 예제, 59개 기존 Python 시험의 이름과 별도 JS/브라우저 인수 기준.
- 실행 순서와 단계별 작업 계획, 폴더 구조와 협업 인계 규칙.
- 앱용 보조 매뉴얼, 18개 등록 자산 데이터, 청해호 가상 신고 15건과 기대 상태.

원격 모델은 비결정적이므로 문장·추론 결과까지 동일하게 생성된다고 보장할 수 없다. 화면의 픽셀 단위 동일성이나 현재 계정의 모델 접근성도 문서만으로 입증하지 않는다. 재구현 평가는 데이터 계약·사용자 동선·업무 정답·경계 보호를 기준으로 한다. 새 AI가 계약을 따르지 않거나 기능을 축약했다면 미완료로 기록한다.

## 편집과 재생성

기능별 원본 `docs/implementation/`, 실행 계획 `docs/handoff/REBUILD_PLAN.md`, 폴더 검토 `docs/FOLDER_GUIDE.md`를 먼저 수정한다. 프로젝트 루트에서 다음을 실행한다.

```sh
python3 docs/handoff/build_bundle.py
```

통합 명세·manifest·ZIP은 생성물이므로 직접 수정하지 않는다. 기존 v2 ZIP은 역사 자료이며 이 묶음과 다르다. 새 묶음을 만든 뒤 링크/JSON/파일 포함 범위와 소스 변경 여부를 확인한다. 소스 대조 날짜가 오래됐다면 문서 계약부터 다시 검토한다.

## 이번 문서 검토에서 개선한 점

기존 18개 문서의 기능별 분리는 유지했다. 소스 위치만으로 부족한 모듈 연결·화면 수치·상태 전환·실행 순서·처음부터 끝까지 이어지는 예제·현재 프롬프트를 추가했다. 현재 구현과 다음 개선을 별도 장으로 나누고, 흩어진 필수 자료는 한 파일로 묶었다. 최신 안내의 MCP/테스트 수 충돌도 바로잡았다.

임시 DB와 규칙 기반 provider로 계약 예제 A(접수/중복), B(정정/분포), D(가정 분리), E(외부 수신/승인) 네 그룹을 로컬 확인했다. 이는 전체 59개 앱 시험·HTTP·브라우저·LIVE·다른 AI 재구현 결과가 아니다. 동일 UI와 업무 품질까지 복원됐는지는 다음 플랫폼의 실제 인수 결과로 판단해야 한다.
