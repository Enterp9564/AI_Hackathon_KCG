# 2팀 발표자료 제작 기준 · 2026-09-27

## 목적과 산출물

- `team.html`: 팀원 설득용 15장. 각자의 프로젝트를 자유롭게 개발하고 세 프로젝트를 API로 연결하자는 협업 제안. Taste 플러그인의 entry-taste, design-taste-frontend, high-end-visual-design을 읽고 밝은 실버·짙은 녹색·큰 제목·다양한 배치로 제작했다.
- `index.html`: 기존 입체형 최종 발표에 스토리를 보강한 20장. 기존 10장 원본은 `index-before-2026-09-27.html`로 보존했다. 새 디자인 적용은 사용자의 비교 후 결정한다.
- 양쪽 모두 발표 대본(N), 작성 근거(B), 장면 선택, 방향키, 전체화면을 제공한다.

## 최신 인원과 과제

최신 인원은 사용자 지정 4번 이미지 기준이다. 2팀은 신진섭·채민주·김대성·송민주, 총 4명이다. 1~3번 이미지는 과제 내용의 근거로 사용하며 이전 인원표를 최신으로 취급하지 않는다.

과제 신청 기준 역할은 Link-One(신진섭), RESAID AI(채민주), AI 상황실(김대성·송민주)이다. 상세 개발 분담은 팀 협의 사항이다. 다른 팀의 구현 수준과 수상 가능성은 제공 자료로 알 수 없다.

## 사용자 요청 반영

각 프로젝트의 화면·기능·개발 자율성을 유지하고, 결과와 확인 요청을 API로 주고받아 현장 협업을 완성한다. 마지막 API 연결 작업과 개발 중 문제 해결을 제안자가 최대한 지원한다는 문구를 팀원용 14장에 넣었다. 발표자는 자신의 약속으로 읽을 수 있다.

최종 연결 이전에 사건·대상자·이벤트 식별과 예제 요청·응답만 작게 합의하는 순서를 제안했다. 현재 API 주소·인증·교환 계약은 확정되지 않았다. 이번 작업은 발표자료 제작이며 앱 API를 새로 구현하지 않았다.

## 기술 스토리의 편집

사용자 제공 `AI_situation_room_RAG_story.md`를 다음 순서로 반영했다.

1. 접수부터 판단·대응안까지 이어지는 AI 상황실
2. 근거 없는 판단·누락·충돌을 어떻게 확인할 것인가
3. RAG로 관련 지침 구절을 검색해 근거 공급
4. 현실의 복합 사고에 여러 매뉴얼을 함께 적용
5. 현장 상태와 적용 조건을 대조해 대응안 구성
6. 세 프로젝트가 API로 상태·확인 요청·결과를 주고받으며 갱신

End-to-End는 업무 흐름의 연결을 뜻하며 단일 모델 종단간 학습의 구현 주장으로 쓰지 않았다. AI는 대응안을 제안하고 최종 운영 판단은 사람이 한다. 매뉴얼을 근거로 해석하되 법령·필수 절차는 제약으로 존중한다. 검색 유사도와 조치 우선순위, RAG 사용과 정확성 보장을 구분한다.

기술 참고: Lewis et al., *Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks*, NeurIPS 2020. <https://arxiv.org/abs/2005.11401>. 검색 자료를 생성 과정에 결합하는 개념을 참고했으며 연구의 성능 수치를 우리 프로젝트에 적용하지 않았다.

## 주장과 증거

- 현재 앱: 실제 모델 호출·요원 실행·병렬 처리·저장·정정 관련 기존 기록이 있다.
- 현재 검색은 단어 기반이며 벡터 RAG·다중 매뉴얼 의미 검색·MCP·두 모델 비교·세 프로젝트 API는 미완료/목표다.
- 공식 평가 배점과 수상 가능성은 미확인이다. 기술적 강점은 실제 업무 기여와 실행 증거로 제시한다.
- A호 5→7명 발표 예시와 청해호 7→8명 기존 시험을 구분한다.
- HTML 도식은 설명과 설계 제안이다. 실제 앱·API가 작동하는 화면이나 증거 영상으로 소개하지 않는다.
- 속도·비용·정확도·시너지의 정량 개선치는 만들지 않았다. 발표 시간도 실측 전 목표다.

## 디자인 선택

팀원용: Taste 기준을 발표 목적에 맞춰 적용. 레이아웃 변화 6, 움직임 3, 정보 밀도 3. 실버 배경·녹색 단일 포인트·같은 계열 한글 산세리프, 표지·관계도·넓은 비교·수평 순서·지원 약속 장면으로 구성했다. 웹 프레임워크를 추가하지 않고 오프라인 HTML을 유지했다. 작은 세로 화면에는 읽기용 단일 열 배치를 적용했다.

최종 발표용: 기존 짙은 배경·시안 포인트·입체 상황실 장면과 조작법을 유지했다. 새 장면에는 동일한 시각 언어로 관계도와 근거 레이어를 추가했다.
