## 열기

- **팀원 설득용:** `team.html` · 15장 · 약 8분 20초 목표
- **최종 발표용:** `index.html` · 22장 · 10분 목표
- **이전 10장 원본:** `index-before-2026-09-27.html`

HTML을 Chrome·Edge·Safari로 열면 됩니다. 발표 실행에는 서버·인터넷·설치가 필요하지 않습니다. 발표 시간은 실제 리허설 전 목표입니다. 작성 근거 링크까지 옮기려면 `sources/`와 `PRESENTATION_BRIEF.md`도 같은 위치에 복사하세요.

팀원용은 Taste 플러그인의 디자인 스킬을 적용한 밝은 실버·녹색 스타일입니다. 최종 발표용은 기존 어두운 입체 스타일을 유지했습니다. 사용자가 팀원용을 본 뒤 최종 발표 디자인을 결정합니다.

## 조작

- 방향키 / Space / PageDown: 장면 이동
- Home / End: 첫 장면 / 마지막 장면
- N: 현재 장면 발표 대본
- B: 현재 장면 작성 근거·원자료 링크
- F: 전체화면
- Esc: 열린 설명 창 닫기
- 하단 막대: 특정 장면 선택
- 도움말의 움직임 줄이기: 전환 애니메이션 끄기

데스크톱은 16:9 가로 화면을 권장합니다. 팀원용은 작은 세로 화면에서 한 열로 읽고 하단 화살표로 이동합니다. 팀원용 터치는 좌우 스와이프, 세로 이동은 내용 스크롤입니다. 최종 발표용은 기존처럼 전체 캔버스를 비율 축소합니다. 대본·근거 창은 투사 중 보이므로 발표할 때 닫아두세요.

## 근거와 표현 범위

최신 인원은 4번 이미지의 2팀 4명(신진섭·채민주·김대성·송민주)을 사용했습니다. 과제 내용은 1~3번 이미지를 참고했습니다. 이전 인원표는 최신 근거로 쓰지 않습니다.

첨부 `AI_situation_room_RAG_story.md`의 판단→신뢰성 질문→RAG→다중 매뉴얼→복합 사고 스토리를 양쪽에 반영했습니다. End-to-End는 업무 흐름의 연결, AI는 대응안 제안, 사람은 최종 운영 판단으로 표현합니다. 법령·필수 절차는 제약이며 검색 유사도는 조치 우선순위가 아닙니다.

벡터 RAG·MCP·모델 비교·세 프로젝트 API는 미완료/확장 목표로 표시했습니다. 현재 앱의 단어 검색과 벡터 검색, 일반 API와 MCP를 구분합니다. 공식 배점·수상 확률·타 팀 성능·효율 수치를 만들지 않았습니다. 세부 제작 기준은 [PRESENTATION_BRIEF.md](PRESENTATION_BRIEF.md)를 보세요.

HTML의 도식·입체 전환은 기능 설명·설계 제안입니다. 실제 AI/API 호출이나 앱 실행 영상이 아닙니다. 현재 앱 상태는 [13번 문서](../13_현재상태_요구사항_인수인계.md)를 따릅니다. 발표자료 제작 과정에서 앱 기능을 바꾸거나 새 LIVE 시험을 하지 않았습니다.

## 수정과 기록

장면 데이터와 대본은 각 HTML 안의 `slides`, 출처는 `references`에 있습니다. `deck-content.json`은 두 발표의 문구·대본·출처를 모은 편집용 사본입니다. 자동 반영되지는 않으므로 수정할 때 HTML과 함께 갱신합니다.

`sources/`는 발표 당시 참고 문서와 사용자 제공 이미지의 사본입니다. 현재 구현 상태의 단일 기준은 루트 13번 문서이며 사본은 자동 갱신되지 않습니다. 원자료는 변경하지 않았습니다.

검증 기록은 [CONTENT_REVIEW.md](CONTENT_REVIEW.md)의 2026-09-27 항목에 이어 기록합니다.
