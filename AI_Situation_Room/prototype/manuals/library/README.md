# HAEON 구난구조 로컬 자료

> 2026-09-28 · 공개 국제 SAR 자료로 만든 교육·해커톤용 초안. 내부 매뉴얼은 향후 추가한다.

## 먼저 볼 자료

**[국제 SAR 기반 초안](international/README.md)**이 이번 준비의 중심이다. AMSA 2026 SAR 매뉴얼과 IMO 공개 회람 5개의 PDF 원본, 페이지별 추출 텍스트, 한국어 분야별 문서 8개, 선별 구절 14개를 보관했다.

> HAEON은 보안상 내부 자료 사용이 제한되고 해커톤 준비 시간이 짧은 점을 고려해, 공개된 국제 SAR 지침과 IAMSAR를 참고하여 작성된 해외 공개 SAR 매뉴얼을 바탕으로 판단 보조 초안을 구성했습니다. 향후 국내 지침·내부 승인 매뉴얼과 현장 전문가 검토를 반영할 계획입니다.

이는 발표에 사용할 수 있는 정확한 설명이다. IAMSAR 최신판 전체 확보, 국내 SOP 준수 검증, RAG·로컬 LLM 연결 완료를 뜻하지 않는다.

## 현재 사용할 수 있는 것

- 파일은 인터넷 없이 읽을 수 있다. 출처 사이트 접속은 별도다.
- 기존 앱의 자료 첨부에서 `international/topics/`의 필요한 Markdown 파일을 세션에 추가하고 검토를 요청할 수 있다. 기존 첨부 단어 검색의 범위 안에서 동작하며 이 경로의 실제 실행은 이번에 시험하지 않았다.
- 향후 로컬 검색기는 `international/chunks.jsonl`의 선별 구절과 `sources.json`의 출처를 읽도록 연결한다. 현재 앱은 이 폴더를 자동으로 읽지 않는다.
- 원본 전체 텍스트는 추출 자료이며, 전문가 검토를 마친 운용 지침 목록이 아니다. 선별 구절과 별도로 취급한다.

## 보조 자료

먼저 조사한 국내 공개 자료는 아래에 보존한다. 국제 초안의 운용 근거와 자료 유형을 혼합하지 않는다.

- [접수와 근거 구분](topics/01-intake.md): 기존 프로젝트 초안.
- [익수·물놀이](topics/02-water-rescue.md): 대국민 안전 안내.
- [갯벌·연안 고립](topics/03-coastal-isolation.md): 과거 안전수칙 공지.
- [환자 이송·화재](topics/04-transport-fire.md): 실제 사건 보도.
- [충돌·오염](topics/05-collision-pollution.md): 훈련 사례.
- [IAMSAR 소개](topics/06-sar-coordination.md): 권별 소개, 본문 아님.

보조 자료의 [출처](sources.json), [구절](chunks.jsonl), [평가 사례](evaluation-cases.json)는 국제 자료와 별도 파일이다. 보조 평가의 ‘계산 근거 미확보’는 해당 보조 묶음의 범위를 뜻한다. 국제 원본을 추가한 뒤에도 검증된 계산 프로그램은 미구현이다.
