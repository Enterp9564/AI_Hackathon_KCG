# 실종·표류·수색 계획

> HAEON(해온) 공개 국제 SAR 기반 초안 · 2026-09-28
> 교육·해커톤용 판단 보조 자료. 공식 번역·국내 승인 SOP가 아니다. 최종 현장 판단은 담당자가 수행한다.

## 확인할 사건 정보 — HAEON 구성

- 마지막 확인 위치·시각·정확도
- 실측·예보 구분, 바람·해류와 대상 특성
- 이전 수색의 실제 완료 범위와 미수색 구역

## 확인 사실과 수색 가정

- 구절 ID: `sar-draft:facts-assumptions:v1`
- 근거: [2026 Edition Version 1](https://www.amsa.gov.au/sites/default/files/2026-03/natsar-manual-2026.pdf)
- 로컬 원본: [amsa-natsar-2026.pdf](../originals/amsa-natsar-2026.pdf)
- 위치: Vol.2 §§2.8.1–2.8.8, 3.2.3–3.2.4; 인쇄 108,121쪽 · PDF 110, 123쪽

수색 정보는 출처별로 수집하고 신뢰성을 평가하며, 새 정보가 들어오면 우선 구역과 방법을 다시 검토한다. 확인된 사실과 가정을 분리하고 가정은 반복해서 재평가한다. 마지막 확인 위치, 이동 의도, 대상자의 상태, 현장 환경, 이전 수색 결과를 함께 본다. 오래 반복한 가정이 사실처럼 굳어지지 않게 한다.

### 적용 제한

- 검토에 활용한 외부 보고가 자동으로 확정 사실이 되는 것은 아니다.

## 수색 계획에 필요한 입력

- 구절 ID: `sar-draft:search-inputs:v1`
- 근거: [2026 Edition Version 1](https://www.amsa.gov.au/sites/default/files/2026-03/natsar-manual-2026.pdf)
- 로컬 원본: [amsa-natsar-2026.pdf](../originals/amsa-natsar-2026.pdf)
- 위치: Vol.2 §§3.1.1–3.1.2, 3.2.1, 3.2.10–3.2.16; 인쇄 120,122쪽 · PDF 122, 124쪽

수색 계획에는 사건 위치와 오차, 이후 이동·표류와 오차, 기준 위치, 가용 자원, 수색 구역·방법, 조정·보고 계획이 필요하다. 기준 위치인 datum은 시각과 불확실성을 가진 추정치다. 표류가 계속되면 새 자료를 반영해 갱신한다. 수색 계획을 세울 때 발견 이후의 구조 계획도 함께 준비한다.

### 적용 제한

- LLM이 원문을 읽는 것만으로 검증된 표류·확률 계산기가 되지 않는다.
- 현 앱에는 검증된 수색구역·탐지확률 계산기가 없으므로 임의 수치를 제시하지 않는다.

## 우선 확인 질문 — HAEON 제안

원문의 공식 서식이 아니라 현재 앱에서 사용할 질문 초안이다.

- 마지막 확인 위치와 시각의 근거는 무엇인가?
- 확인 사실을 제외하면 어떤 가정에 수색 제안이 의존하는가?

## 보고 작성 형식 — HAEON 제안

현재 확인된 상황 → 관련 구절과 적용 이유 → 제안 1~2개 → 추가 확인사항 → 출처. 출동·처치·상황 갱신을 실행했다고 표현하지 않는다. 근거가 부족하면 부족한 입력이나 지침을 명시한다.
