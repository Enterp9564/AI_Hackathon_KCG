# 화재·침수·좌초·예인 지원

> HAEON(해온) 공개 국제 SAR 기반 초안 · 2026-09-28
> 교육·해커톤용 판단 보조 자료. 공식 번역·국내 승인 SOP가 아니다. 최종 현장 판단은 담당자가 수행한다.

## 확인할 사건 정보 — HAEON 구성

- 위험의 위치·진행·고립 인원·대피 상태
- 외부 지원의 역할·도착 조건·제약
- 선박의 현 상태와 현장 책임자의 판단

## 화재·침수·예인·의료 외부 지원

- 구절 ID: `sar-draft:external-support:v1`
- 근거: [MSC.1/Circ.1183](https://wwwcdn.imo.org/localresources/en/OurWork/Safety/Documents/MSC.1-Circ.1183%20-%20Guidelines%20On%20The%20Provision%20Of%20External%20Support%20As%20An%20Aid%20To%20Incident%20Containment.pdf)
- 로컬 원본: [imo-msc-1183.pdf](../originals/imo-msc-1183.pdf)
- 위치: Annex §§2.1, 3.1–3.4, 4.1–4.2, 5.2–5.4, 6.3, 7.1 · PDF 3, 4, 5, 6쪽

사고선의 인명 안전을 위해 소방·구출·손상통제·예인·의료 등 외부 전문 지원을 검토할 수 있다. 지원의 능력·제한·연락·수송·지휘 체계를 사전에 확인하고 선박·선사·SAR 기관의 대응을 조정한다. 인명 안전이 우선이며 선박의 안전한 체류 가능성에 따라 지원과 대피 필요를 검토한다.

### 적용 제한

- 지원 유형을 소개하는 지침이며 모든 사고에서 모든 세력을 출동시키라는 뜻이 아니다.
- 선박에 머물거나 퇴선하라는 일률적 지시를 만들지 않는다. 현장 판단과 선박 상태가 필요하다.

## 우선 확인 질문 — HAEON 제안

원문의 공식 서식이 아니라 현재 앱에서 사용할 질문 초안이다.

- 지원 목적은 인명 구조, 위험 억제, 이송 중 무엇인가?
- 현재 선박 상태를 근거로 필요한 전문 지원이 확인됐는가?

## 보고 작성 형식 — HAEON 제안

현재 확인된 상황 → 관련 구절과 적용 이유 → 제안 1~2개 → 추가 확인사항 → 출처. 출동·처치·상황 갱신을 실행했다고 표현하지 않는다. 근거가 부족하면 부족한 입력이나 지침을 명시한다.
