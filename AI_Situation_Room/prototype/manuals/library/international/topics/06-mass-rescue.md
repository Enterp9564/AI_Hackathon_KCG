# 다수 인명·명부·이송 조정

> HAEON(해온) 공개 국제 SAR 기반 초안 · 2026-09-28
> 교육·해커톤용 판단 보조 자료. 공식 번역·국내 승인 SOP가 아니다. 최종 현장 판단은 담당자가 수행한다.

## 확인할 사건 정보 — HAEON 구성

- 사고선 대상자 명부와 식별 기준
- 현재 위치·구조·재이송·최종 인계의 구별
- 각 기관의 담당 범위와 갱신된 보고

## 다수 인명·기관의 조정

- 구절 ID: `sar-draft:mass-accountability:v1`
- 근거: [COMSAR/Circ.31](https://wwwcdn.imo.org/localresources/en/OurWork/Safety/Documents/COMSAR.1-Circ.31%20-%20Guidance%20For%20Mass%20Rescue%20Operations.pdf)
- 로컬 원본: [imo-comsar-31.pdf](../originals/imo-comsar-31.pdf)
- 위치: Annex §§7, 10–11, 17–19, 26; 인쇄 Annex 2–4쪽 · PDF 4, 5, 6쪽

대량구조에서는 기관별 역할과 자원 동원을 조정하고, 선장에게 중복해서 정보를 요구하는 부담을 줄인다. 승선자와 구조자의 소재·인원 추적을 우선하며, 명부와 이송·인계 정보를 이어 관리한다. 사전 계획과 합동훈련도 준비 요소다.

### 적용 제한

- 원문은 대량구조 지침이며 국내 재난 지휘체계의 법적 배분을 정하지 않는다.
- 현재 앱의 재이송 중복 집계 방지는 프로젝트 데이터 규칙이며 국제 원문의 수식이 아니다.

## 우선 확인 질문 — HAEON 제안

원문의 공식 서식이 아니라 현재 앱에서 사용할 질문 초안이다.

- 총원과 각 위치의 인원 차이가 원문으로 설명되는가?
- 새 구조인가, 이미 구조된 사람의 재이송인가?

## 보고 작성 형식 — HAEON 제안

현재 확인된 상황 → 관련 구절과 적용 이유 → 제안 1~2개 → 추가 확인사항 → 출처. 출동·처치·상황 갱신을 실행했다고 표현하지 않는다. 근거가 부족하면 부족한 입력이나 지침을 명시한다.
