# 조난 접수·신고 평가·기록

> HAEON(해온) 공개 국제 SAR 기반 초안 · 2026-09-28
> 교육·해커톤용 판단 보조 자료. 공식 번역·국내 승인 SOP가 아니다. 최종 현장 판단은 담당자가 수행한다.

## 확인할 사건 정보 — HAEON 구성

- 사고 위치·좌표의 기준시각·최신 확인 출처
- 선박과 인원, 현재 인명 위험, 연락 수단
- 확인된 사실과 미확인·상충 보고

## 신고의 긴급성과 추가 확인

- 구절 ID: `sar-draft:intake-evaluate:v1`
- 근거: [2026 Edition Version 1](https://www.amsa.gov.au/sites/default/files/2026-03/natsar-manual-2026.pdf)
- 로컬 원본: [amsa-natsar-2026.pdf](../originals/amsa-natsar-2026.pdf)
- 위치: Vol.2 §§2.5.1–2.5.3, 2.5.9–2.5.14; 인쇄 97–98쪽 · PDF 99, 100쪽

접수한 보고의 신뢰성, 긴급성, 필요한 대응 범위를 검토한다. 사건의 성격과 대략적인 위치가 알려지면 초기 대응과 추가 정보 수집을 병행하는 접근을 설명한다. 확인되지 않은 정보가 있다고 해서 긴급한 검토를 모두 뒤로 미루는 방식은 피한다. 이 원칙을 앱에 적용할 때는 불확실성의 표시와 담당자의 결정 권한을 함께 유지한다.

### 적용 제한

- 호주 SAR 대응 지침의 요약이다. 국내 비상단계 자동 선언 기준이 아니다.
- HAEON 외부 수신함의 담당자 승인 절차를 생략하는 근거로 사용하지 않는다.

## 원문과 시간순 기록

- 구절 ID: `sar-draft:incident-log:v1`
- 근거: [2026 Edition Version 1](https://www.amsa.gov.au/sites/default/files/2026-03/natsar-manual-2026.pdf)
- 로컬 원본: [amsa-natsar-2026.pdf](../originals/amsa-natsar-2026.pdf)
- 위치: Vol.2 §§2.3.1–2.3.8; 인쇄 96쪽 · PDF 98쪽

사건별로 수신 정보와 시행한 조치를 시간순으로 기록하고 원문·서식·지도 등 지속적으로 참조할 자료를 연결한다. 계획상 배정된 수색 구역과 실제 수색한 구역을 구분하며, 배정 후 미수색한 부분이 재배정에서 빠지지 않게 한다. 대상자를 찾지 못한 채 중단한 경우에도 재개할 수 있도록 근거와 수색 기록을 보존한다.

### 적용 제한

- 현재 앱에는 수색구역 GIS·실제 항적 검증이 구현되어 있지 않다.

## 조난 위치와 인계 확인

- 구절 ID: `sar-draft:alert-location:v1`
- 근거: [MSC/Circ.959](https://wwwcdn.imo.org/localresources/en/OurWork/Safety/Documents/Documents%20relevant%20to%20SAR/MSC-Circ.959%20Interim%20procedures%20for%20MRCCs%20on%20receipt%20of%20distress%20alert.pdf)
- 로컬 원본: [imo-msc-959.pdf](../originals/imo-msc-959.pdf)
- 위치: Annex 1, Annex 2 · PDF 3, 5쪽

조난 접수 절차는 위치 포함 여부와 관할 구역에 따라 확인·전달·조정 인계를 다룬다. 위치가 없거나 오래된 경우에도 위치 확인과 관계기관 연락이 필요하다. 인계 요청과 상대 기관의 인수 확인을 구별한다.

### 적용 제한

- 2000년의 잠정 회람이며 최신 통신별 절차와 함께 확인해야 한다.
- 실제 DSC·위성통신 송신 절차를 이 요약으로 실행하지 않는다.

## 우선 확인 질문 — HAEON 제안

원문의 공식 서식이 아니라 현재 앱에서 사용할 질문 초안이다.

- 현재 인명 위험과 위치 중 무엇이 먼저 확인돼야 하는가?
- 같은 보고의 재전송인지 새로운 상황 변화인지 구분됐는가?

## 보고 작성 형식 — HAEON 제안

현재 확인된 상황 → 관련 구절과 적용 이유 → 제안 1~2개 → 추가 확인사항 → 출처. 출동·처치·상황 갱신을 실행했다고 표현하지 않는다. 근거가 부족하면 부족한 입력이나 지침을 명시한다.
