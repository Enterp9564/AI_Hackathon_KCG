## 2026-09-27 · MCP 수신함과 담당자 인용 승인

사용자 지정 흐름을 구현했다. Link-One·RESAID AI별 토큰/알림, 외부 사건 ID 연결, 수신 원문·상태·이력 저장, 인용하여 전송·나중에·반영 안 함을 제공한다. 수신만으로 AI/현재 장부/채팅을 변경하지 않는다. 인용 승인과 기존 enqueue는 하나의 SQLite 트랜잭션이다. 같은 보고 재수신·다중 클릭·거절과 승인 경합·삭제 사건 재사용을 보호한다. 일반 채팅 초안·가정·선택 모드를 인용 전송이 덮어쓰지 않는다.

MCP는 별도 선택적 포트의 2025-11-25 Streamable HTTP JSON 응답 방식이며 submit_field_report만 노출한다. loopback 기본, 명시적 host/허용 IP로 핫스팟 수신 가능. 로컬 UI의 보안 검사는 유지했다. 프로젝트 토큰 준비 도구와 재시도 가능한 테스트 송신 CLI를 추가했다. .secrets/mcp 인증 파일을 로컬에 준비했으며 비밀/사용자 runtime은 커밋 대상에서 제외한다.
