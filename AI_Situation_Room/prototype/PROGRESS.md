AMSA National Search and Rescue Manual 2026 Edition Version 1(519쪽)과 IMO 공개 회람 MSC/Circ.959, MSC.1/Circ.1183, MSC.1/Circ.1447, COMSAR/Circ.31, MSC.1/Circ.1218 원본을 로컬에 보관했다. 총 6개 PDF·561쪽이며 페이지별 추출 텍스트와 파일 해시를 남겼다. 국제 한국어 초안 8개·선별 구절 14개, 국내 보조 문서 6개·구절 6개, 평가 사례 초안 35개를 작성했다.

국제 초안은 접수·조정·수색 계획·구조 자원·화재/침수 외부 지원·대량구조·의료정보 인계·종결을 다룬다. 사실·가정·현장 보고, 등록 자산·실제 가용성, 요청·인수 확인을 구별한다. 원문 절·페이지와 적용 제한을 보관하며 HAEON의 확인 질문은 공식 원문과 구분한다. 원본 561쪽 전체의 전문가 검토를 완료한 것으로 표시하지 않는다.

IAMSAR는 공식 소개와 구매 출판물 안내를 확인했고 유료 본문 전체는 확보하지 않았다. AMSA 원문은 IAMSAR를 고려해 작성된 호주 국가 매뉴얼이며 IAMSAR 자체 또는 국내 승인 SOP로 표시하지 않는다. 원문 판권·출처를 보존했고 내부 자료는 읽거나 추가하지 않았다. 기존 기본 매뉴얼·앱 코드·사용자 runtime과 키는 변경하지 않았다. 신규 자료의 GitHub 업로드도 하지 않았다.

### 확보·검증 기록

- 다운로드 첫 시도: 샌드박스 DNS 실패. 네트워크 권한을 적용한 Python 시도는 인증서 오류로 실패했다. 인증서 검증을 유지하는 시스템 curl로 IMO 5개와 AMSA 원본을 확보했다.

- 국내 후보 중 질병관리청 저체온증 페이지는 본문 열기 실패로 제외했고, 도봉구 안내는 제목·설명 해석 문제가 있어 운용 구절로 채택하지 않았다.
- 정적 검사 최초 실행: 작성 전 manifest.json을 가리키는 링크 1건 실패. 무결성 목록 생성 후 재검사 PASS.
- 재검사: 원본 PDF 6개의 해시·페이지 수, 561개 페이지 텍스트 레코드의 순서, 구절 20개의 ID·역할·본문 해시·문서 일치, 출처·인용 페이지·평가 참조를 확인했다. 평가 사례 35개는 모두 not_run이며 검색 품질 시험 통과를 뜻하지 않는다. 당시 로컬 링크 98건과 기존 인수인계 기준 앱 코드 25개 파일의 동일성을 확인했다. 네트워크 연결을 차단하는 검사 설정에서도 로컬 파일 검증이 완료됐다.
- 대표 PDF 7개 페이지를 렌더링해 판권·절·쪽번호를 육안 대조했다. 추출 텍스트는 표·그림을 완전히 대체하지 않으므로 원본을 함께 보관한다.
- 앱 단위/HTTP/브라우저/LIVE/로컬 LLM/검색 성능 시험은 이번에 실행하지 않았다. 자동 RAG·로컬 모델·일반 웹 검색 연결은 미구현이다.


## 2026-09-28 · 국제 SAR 검색·요원 연동 구현계획

사용자가 벡터 DB 기반 매뉴얼과 사전 파싱·로컬 LLM 참조 흐름의 구현계획을 요청했다. [전체 계획](../docs/superpowers/plans/2026-09-28-sar-rag.md)과 자료 정제·검색·요원 연동·로컬 모델의 별도 문서 4개를 작성했다. 파일별 책임·함수/데이터 계약·작업 체크리스트·시험 명령·완료/복구 기준을 포함한다.

첫 단계는 기존 14개 한국어 요약으로 검색·연결을 검증한다. 이후 원문 561쪽의 처리 상태를 기록하며 확인된 절부터 검색 범위를 확대한다. Qdrant 로컬 모드·다국어 임베딩·키워드 검색 결합은 구현 제안이며 설치하거나 제품 선택을 확정한 상태가 아니다. 추가 검색은 전문요원당 1회로 제한하고, 로컬 생성 모델은 대상 장비 평가 후 별도 연결한다.

기존 단순 연결의 6~12시간 추정과 새 범위를 구분했다. 벡터 검색·색인/판본 관리·근거 기록·통합 검증을 포함한 M1은 2~4 작업일, 핵심 원문 확대 M2는 추가 2~5 작업일의 초기 추정이다. 전체 전문 검토와 로컬 모델 성능은 이 추정으로 보장하지 않는다.

이번 변경은 계획·문서 연결·인수인계 기록뿐이다. 앱 코드·runtime·키·원본/정제 데이터·모델 의존성은 변경하지 않았다. 단위/HTTP/브라우저/LIVE/로컬 LLM·실제 검색 품질 시험은 미실시다. GitHub 업로드와 인수인계 ZIP 재생성도 수행하지 않았다.

문서 검증 결과: 계획 5개와 관련 안내·인수인계의 로컬 링크 59개 누락 0건, 계획 필수 절·함수/데이터 계약의 연결을 확인했다. 앱 기준 파일 25개의 SHA-256이 기존 인수인계 manifest와 일치한다. 생성 모델과 장비는 L1 평가 후 결정하도록 남겼으며, 실행할 때의 예상 PASS 문구를 이번 실행 결과로 취급하지 않는다.


## 2026-09-28 · 링크온 상황 요약 JSON 조회 계획

사용자 선택은 **링크온이 필요할 때 조회**다. [분석·계약 설계](../docs/superpowers/specs/2026-09-28-linkone-summary-api.md), [작업별 구현계획](../docs/superpowers/plans/2026-09-28-linkone-summary-api.md), [가상 JSON 4개와 수신 안내](../docs/contracts/linkone-summary-v1/README.md)를 작성했다.

1차는 기존 연동 포트의 일반 HTTP GET, 사건별 공유 설정, 허용 필드 투영, 현재/과거/미생성 요약 구분이다. 현재 장부와 AI 보고를 분리하며 revision으로 같은 장부 버전의 새 보고도 구별한다. 후속 MCP 조회는 같은 JSON을 사용한다. 기존 현장 보고 수신은 변경하지 않으며 웹훅·수신 v2는 후속 범위다.

준비 상태 점검과 이번 문서 작업을 구분한다. 앞선 로컬 실행 조회는 최초 샌드박스에서 PermissionError로 차단됐고, 로컬 조회 권한 적용 후 capabilities.mcp=false를 확인했다. 기본 8862 listener가 없었고 토큰 파일 존재만 확인했으며 값은 출력하지 않았다. 임시 DB/로컬 포트로 기존 MCP·수신함 단위/HTTP 시험 16개가 OK였다. 신규 요약 API는 구현·시험하지 않았고 브라우저·링크온 실제 앱·LIVE 시험도 이번에 실행하지 않았다.

이번 변경은 계획·설계·예제·문서 연결뿐이다. 앱 코드·runtime·비밀·모델 설정·실행 서버를 변경하지 않았다. 구현계획의 예상 PASS 문구와 미체크 작업을 실행 결과로 해석하지 않는다.

후속 제공된 링크온 DB 스키마는 참고자료로 읽고 [대응 분석](../docs/contracts/linkone-summary-v1/linkone-db-mapping.md)에 출처 해시와 필드 의미를 기록했다. room.id(UUID) 사건 연결 제안을 JSON 예제에도 적용했다. room.mode와 해온 실행 mode를 분리하고, 인원 집계·병합·취소·지연 데이터는 실제 도메인 규칙 확인이 필요한 후속 수신 범위로 남겼다. 원본 재생성 명령·DB 접근·스키마 변경은 실행하지 않았다.

문서 검증: 관련 Markdown 8개·로컬 링크 79건에서 누락 0건, 가상 JSON 4개와 revision 해시 3개, Python 수신 예제 1개의 구문을 확인했다. 계획 6개 작업은 모두 미실행이다. 작성 전 기준 앱 Python/정적 파일 16개의 SHA-256과 사용자 제공 스키마 원본 해시가 그대로임을 확인했다. 이는 문서/예제 검사이며 신규 API 실행 시험이 아니다.


## 2026-09-28 · 링크온 SSH·DB 접속 준비 회신

사용자가 전달한 링크온 개발자 회신을 기준으로 [외부 전달 문서](../docs/handoff/LINKONE_CONNECTION_REPLY.md)를 작성했다. 현재 제공 범위는 SSH 터널을 통한 링크온 → 해온 읽기 전용 조회다. 기존 해온 요약 조회 API 설계는 보존하되 이번 접속·연동 범위에 포함하지 않으며, 링크온 측과 합의된 양방향 연동으로 표현하지 않는다.

전용 공개키는 아직 생성·전달·등록하지 않았다. 문서에는 접속 조건, 훈련 사건, 초기 조회 대상, 5초 간격 제안·1,000건 제한, 공개키 등록 요청과 sync 응답/인증/변경 범위 확인사항을 담았다. DB 비밀번호·개인키·토큰 값은 기재하지 않았다. 공개키가 포함된 등록 요청 완료본과 구별한다.

이번 작업은 문서 작성과 정적 확인뿐이다. 앱 코드·사용자 runtime·비밀 파일은 변경하지 않았고 도구 설치·SSH/DB/API 접속·단위/HTTP/브라우저/LIVE 시험은 실행하지 않았다.


### 2026-09-28 · 링크온 후속 회신 반영

[접속 준비 문서](../docs/handoff/LINKONE_CONNECTION_REPLY.md)에 인증 없는 GET /api/sync, 최대 20개 rooms, all/rooms 문자열 변경 비교, 재시작 기준 재조회, 5초 주기, 이력 30초 중복 조회·ID 중복 제거, person/transfer 재조회, 종결 후 재개 지원을 반영했다. 회신의 권장 방식과 해온의 보완 검토를 구분하며 30초 중복 조회만으로 무누락을 보장하지 않는다. 공개키 생성·전달·등록은 미완료이고 전달 경로에는 예시 표기가 남아 있다. 이번 변경은 문서만이며 외부 API·SSH·DB 접속과 앱 시험은 미실시다.


## 2026-09-28 · 링크온 로컬 접속 준비 실행

사용자 지시로 [접속 준비와 실행 안내](../docs/handoff/linkone-access/README.md), 공개키 등록 요청·공개키 파일을 준비했다. 개발 전용 Ed25519 키는 사용자 SSH 폴더에 생성했고 개인키 권한은 600이다. 전달받은 DB 비밀번호와 전용 SSH 설정·검증한 known_hosts·psycopg 3.3.6 가상환경은 기존 Git 제외 경로 prototype/.secrets/linkone에 보관했다. 비밀값은 문서에 포함하지 않았다. 암호 없는 키이며 기존 SSH 기본 설정은 변경하지 않았다.

수동 점검 도구 prototype/linkone_access.py는 local/sync/tunnel/db를 제공한다. DB 점검은 읽기 전용 옵션과 권한 메타데이터 확인 후 지정 사건 핵심 5개 테이블에서 최대 20행씩 조회하며 결과 본문은 출력·저장하지 않는다. 자동 수신·장부 변경·모델 호출은 구현하지 않았다.

실행 결과: SSH 서버 지문 일치, 시스템 curl/API 점검 정상, 로컬 검사·구문 검사·도구 보호 검사 5개 통과, Git 비밀 경로 제외 확인. 첫 Python HTTPS는 URLError로 실패 후 인증서 검증을 유지한 시스템 curl로 성공했다. 비밀번호 저장 첫 시도는 빈 표준입력으로 빈 파일이 생겨 바로잡았고 local 검사 통과를 확인했다. SSH 인증 시험은 Permission denied(publickey,password)로 실패했다. 클라이언트는 공개키만 시도했으며 링크온 담당자의 공개키 등록이 남아 있다.

공개키 메시지 발송·원격 등록·실제 DB 접속/권한/데이터 검증·앱 전체 단위/HTTP/브라우저/LIVE는 미실시다. 기존 실행 앱·사용자 runtime 자료는 변경하지 않았다.


### 공개키 전달 완료 후 개발 환경 재확인

사용자가 공개키 송신 완료를 확인했다. [개발 환경 재확인 기록](../docs/handoff/linkone-access/README.md)에 Python 3.11.9·SQLite 3.45.1·Node v24.7.0·의존성 검사·로컬 키/비밀 권한·Git 제외·공개키 ZIP 일치와 모의 보호 시험 5개 재통과를 기록했다. 변경 API는 정상 응답했지만 SSH 재인증은 255 Permission denied로 실패했다. 등록 반영 여부나 서버 설정 원인은 확인하지 못했다. 원격 DB 접속·실데이터 조회와 앱 전체 회귀/HTTP/브라우저/LIVE는 실행하지 않았다. 이번에는 상태 문서만 수정했으며 설치·키 교체·앱 동작 변경은 하지 않았다.


### 공개키 등록 후 SSH·DB 실접속 성공

링크온 등록 완료 회신 후 검증된 서버 지문으로 SSH 터널 및 linkone/linkone_ro 읽기 전용 DB 연결에 성공했다. 제한 컬럼 4개 SELECT 권한 없음, public 일반·파티션 테이블/컬럼 쓰기 권한 메타데이터 확인. 훈련 사건은 room 1행·나머지 핵심 4개 표 0행이며, 추가 제공 퀸메리호 사건의 최대 20행 샘플은 person 20·person_state 6·person_event 20·transfer 0이었다. 전체 건수/인원수로 해석하지 않는다.
