# RESAID AI

- 담당: **채민주**
- 역할: 대상자 상태에 따른 응급 지원과 필요한 확인사항을 다루는 프로젝트.
- 현재 상태: 협업용 폴더와 안내 문서만 준비했습니다. 실제 코드와 자료는 담당자가 추가합니다.

## 자료 추가

프로젝트 소스·설정 예제·관련 문서를 이 폴더 안에 넣어 주세요. 기존 프로젝트 구조와 개발 방식을 유지해도 됩니다. 업로드 후 필요한 설치·실행 명령과 환경변수 이름을 이 README에 기록합니다. 비밀키 값·실제 개인정보·실행 DB는 올리지 않습니다.

## 협업 방향

Link-One의 현장 정보와 AI 상황실의 확인 요청을 바탕으로 응급 지원 관련 확인사항과 근거를 공유하는 방향을 검토합니다. AI 상황실에 담당자 승인형 MCP 수신 서버가 준비되었습니다. 이 프로젝트의 실제 송신 연결은 아직 구현 전입니다. [도구 계약](../AI_Situation_Room/docs/implementation/17-mcp-transport.md)과 [핫스팟 테스트](../AI_Situation_Room/docs/implementation/18-hotspot-testing.md)를 참고해 submit_field_report를 연결합니다. 결과 조회·송신은 후속 협의 대상입니다.
